## A 剪影

- `shots/acceptance/silhouettes-before.jpg`：接手时五城默认视角，去色、每城 320 px、并排。
- `shots/acceptance/silhouettes-after.jpg`：本分支五城（重庆 / 陆家嘴 / 西安 / 深圳 / 江南），同顺序、同视口、去色、320 px 并排。
- 结论：1 秒内可指认五城；重庆（山脊 / 台地 / 立交 / 吊脚楼）与深圳（超高层矩阵 + 低层村带）不再相像。
- 注意：深圳 after 图用的是 `time=0.95`（霓虹对照），其余城市为各自默认时间。
