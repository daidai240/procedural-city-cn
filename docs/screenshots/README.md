# 视觉对照 · Before / After

两组截图均在相同环境下采集：

- 视口：1440 × 900
- 浏览器：Playwright Chromium（无头，SwiftShader WebGL2）
- 场景：各城市默认机位 1（南岸全景 / 外滩对望 / 城墙全景 / 深圳湾 / 水巷视角）
- 界面：右侧参数面板保持展开

## before/

第一版可运行效果的实机截图。此时城市生成、五种风格、参数联动已经工作，但机位、地形范围、楼宇密度、灯光与雾效仍在第一轮调试中。

## final/

最终交付效果。经过第二轮自测后重点调整：

- 重庆：扩大地形到南岸，修复水陆交接处的深度冲突；增加南岸村落、岸线灯带、轻轨列车与洪崖洞檐口结构；夜景调成暖橙 + 深蓝。
- 陆家嘴：扩大城市范围、加密楼群；重做东方明珠；镜头拉远，让「三件套」完整入画；外滩压低为前景。
- 西安：把几何山体换成柔和远山，城墙、钟鼓楼、大雁塔增加暖光；加密里坊与树木。
- 深圳：镜头拉远到完整天际线；增加海面霓虹倒影、分段岸线、楼体轮廓灯与街面霓虹。
- 江南：默认机位改为贴近水面的巷道视角；降低雾的乳白感，提高白墙/黛瓦对比，增加第二排民居、灯笼、石阶与乌篷船。

> 说明：这是全新项目，没有既有产品 UI 可作对照。`before` 是第一版可运行版本的实机截图，`final` 是本次交付的实机截图；两组都来自真实应用渲染，而不是设计稿。
