# 写实度改进 · 轮次报告

三条军规执行情况：没有重写模块划分；每轮最多 3 项；每项都有改前 / 改后截图与一行验收结论。
所有截图均为 1440 × 900、无头 Chromium（SwiftShader WebGL2）实机渲染，同 seed `20261119`。

复现命令见 `shots/README.md`。

## R1 · P0 三个视觉硬伤

```
轮次：R1
修复：P0-1 夜间压黑、P0-2 拉索白线爆炸、P0-3 建筑不接地 / 重庆没有高差
证据：shots/r1/before|after/chongqing-{default,night-ground,bridge,terrain}.jpg
验收：
  - 深夜档（time=0.95）隐藏建筑后，只看地面能分辨江岸线、道路灯带与至少 4 级高差轮廓 ✓
  - 默认时间 重庆 0.9 → 0.66、深圳 0.94 → 0.66；夜景地面不再是纯黑 ✓
  - 默认视角左侧不再出现扇形放射白线；拉索为实体细杆，退出 bloom ✓
  - 侧视可见连续台地，建筑落在基础 / 挡土墙上，无悬空、无半埋 ✓
  - 量化（tests/measure-ground.mjs，下 55% 地面区域）：中位亮度 5.1 → 19.9，
    #101418 以下占比 95.1% → 45.6%，“黑到 12 以下”占比 65.2% → 4.1% ✓
残留：洪崖洞仍是 5×7 发光方盒；李子坝、立交、江岸未改（下一轮）
```

实现要点：

- `context.js` 新增 `nightSurface()`：地面 / 地形夜间基础自发光 + 掠射湿反射，雾随高度衰减；
  `applyNight()` 从雾色 / 天际色生成反照色。
- 夜间半球光 +0.24、雾密度 ×0.78、雾色改为深蓝灰；水面反射 ×1.5。
- `chongqing.js` 新增半岛山脊（高差约 70 m），坡面量化成 ~4.8 m 台地；
  建筑基础改为「四角 + 中心」五点采样，向下延伸到最低点 -3 m，露出部分生成带 0.6 m 压顶的挡土墙；
  按高程分带：低处密而矮、高处疏而高，陡坡禁止 20 层以上塔楼。
- 拉索改为每塔 12 根实体圆柱（半径 0.18 m），无强自发光、低于 bloom 阈值；
  桥面改实体箱梁并补河中桥墩，删除 `LineSegments`。
- 一并修复契约问题：`traffic.js` / 实例 seed 的 `Math.random()` 改为确定性 RNG。

## 性能预算（同一无头环境的 draw call / 三角形）

| 城市 | draw call 改前 → 改后 | 三角形 改前 → 改后 |
| --- | --- | --- |
| 重庆 | 500 → 386 | 582k → 606k |
| 陆家嘴 | 382 → 466 | 83k → 87k |
| 西安 | 1,290 → 1,290 | 66k → 81k |
| 深圳 | 492 → 472 | 162k → 143k |
| 江南 | 2,606 → 266 | 92k → 152k |

- 江南的实例化是这一轮最大的工程收益；重庆默认机位也从 500 降到 386（不同机位会有差异）。
- 陆家嘴上升来自新增外滩 18 栋与江面反光，换来“能看见江 / 外滩”的构图。
- 西安仍是 1,290 次，是 P2 性能的第一优先级；headless FPS 不能代表真实 GPU，未作为验收依据。
